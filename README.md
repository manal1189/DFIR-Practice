# DFIR Practice

A collection of hands-on Digital Forensics and Incident Response (DFIR) labs focusing on evidence analysis, investigation methodology, and professional reporting.

## About This Repository
This repository documents practical DFIR exercises designed to simulate real-world forensic investigations.  
Each lab follows a structured forensic approach, from evidence acquisition to analysis and reporting.

## Labs
- USB Forensic Analysis
- Disk Image Analysis
- Memory Forensics (Coming Soon)

## Methodology
Each lab includes:
- Defined investigation objectives
- Evidence analysis process
- Tool usage and justification
- Key findings
- Final forensic report

## Tools Used
- Autopsy
- FTK Imager
- Volatility

## Disclaimer
All labs are conducted in a controlled environment using legally obtained data for educational purposes only.
